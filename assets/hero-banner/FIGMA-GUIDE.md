# راهنمای بنر صفحه اصلی (Hero Banner)

## مشخصات
- **ابعاد:** ۱۴۴۰ × ۵۰۰ (دسکتاپ) · ۲۸۸۰ × ۱۰۰۰ (@2x)
- **رنگ‌ها:** `#115E59` → `#8B5CF6` (گرادیان افقی)
- **متن:** سفید · فونت **IRANSansX Bold**
- **چیدمان:** متن چپ · ایلاستریشن راست

## فایل‌ها

| فایل | کاربرد |
|------|--------|
| `png/hero-banner.png` | بنر کامل آماده (۱۴۴۰×۵۰۰) |
| `png/hero-banner@2x.png` | نسخه Retina |
| `png/hero-banner-tablet.png` | نسخه تبلت (۱۲۰۰×۴۲۰) |
| `png/hero-illustration.png` | فقط گرافیک سمت راست |
| `svg/hero-banner.svg` | نسخه وکتور برای ویرایش |
| `hero-banner.html` | پیش‌نمایش وب با IRANSansX |
| `fonts/IRANSansX-*.ttf` | فونت برای Figma و وب (نیاز به لایسنس رسمی فونت ایران) |

## ایمپورت در Figma

### روش سریع
1. `png/hero-banner.png` را Drag & Drop کنید

### روش قابل ویرایش
1. `svg/hero-banner.svg` را ایمپورت کنید
2. فونت IRANSansX را در Figma نصب کنید (از پوشه `fonts/`)
3. متن را انتخاب کنید و فونت را **IRANSansX Bold** بگذارید
4. گرافیک راست را با `hero-illustration.png` جایگزین یا جابه‌جا کنید

### ساخت Color Style
- `Primary/Teal` → `#115E59`
- `Primary/Purple` → `#8B5CF6`
- `Text/White` → `#FFFFFF`

## استفاده در وب
فایل `hero-banner.html` را باز کنید یا استایل‌های آن را در پروژه کپی کنید.
